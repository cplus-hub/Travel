---

## 🛠️ 技術棧 (Technology Stack)

- **靜態網站生成器**: Hugo
- **前端**: HTML5, CSS3 (Flexbox, Grid, CSS Variables), Vanilla JavaScript (ES6+)

---

## 🚀 本地端運行 (Local Setup)

1.  確保您已安裝 Hugo。
2.  將此專案複製到您的本地電腦：
    ```bash
    git clone https://github.com/cplus-hub/Travel.git
    ```
3.  進入專案目錄：
    ```bash
    cd Travel
    ```
4.  啟動 Hugo 本地伺服器：
    ```bash
    hugo server
    ```
5.  在瀏覽器中開啟 `http://localhost:1313/` 即可看到網站。
